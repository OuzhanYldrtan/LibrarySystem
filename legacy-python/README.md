# Eski Python sürümü

Bu klasör, projenin React + NestJS + MCP mimarisine geçilmeden önceki Python uygulamasını arşivler.

Güncel uygulama bu dosyaları kullanmaz. Güncel geliştirme sunucusu proje kökünde `pnpm dev` veya `./scripts/dev.sh` ile başlatılır.

Arşiv içeriği:

- `server.py`: Eski Python HTTP sunucusu ve PostgreSQL uygulaması
- `test_chatbot.py`: Eski Python testleri
- `static/`: Eski HTML, CSS ve JavaScript arayüzü
- `requirements.txt`: Eski Python bağımlılıkları
- `.venv/`: Eski Python sanal ortamı
- `library.db`: Önceki yerel veritabanı dosyası
- `__pycache__/`: Python önbelleği
